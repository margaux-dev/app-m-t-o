# 🌤️ Widget Météo Glassmorphism & 3D

Widget météo moderne et minimaliste conçu avec un style **Glassmorphism** (effet verre dépoli) et des éléments d'interface en relief 3D.

---

## ✨ Fonctionnalités

* 🔍 **Recherche de ville** : Géolocalisation dynamique de n'importe quelle ville dans le monde.
* 🌡️ **Météo en direct** : Affichage en temps réel de la température actuelle via l'API Open-Meteo.
* 🎨 **Design Glassmorphic & 3D** : Champ de recherche avec ombre interne en relief, bouton style "goutte d'eau" et carte translucide (`backdrop-filter`).
* 📱 **Compatibilité Cross-Platform** : Rendu optimisé et responsive pour macOS et Windows.

---

## 🛠️ Stack Technique

* **HTML5** : Structure sémantique du widget.
* **CSS3** : Propriétés `backdrop-filter`, ombres complexes `inset`, gradients et gestion du responsive.
* **JavaScript (Vanilla)** : Manipulation du DOM et requêtes asynchrones (`async/await`, `fetch`).
* **Open-Meteo API** : API gratuite de géolocalisation et données météorologiques (sans clé d'API requise).

---

## 🚀 Lancement Rapide

1. Ouvre le fichier `index.html` dans ton navigateur (ou via l'extension **Live Server** sur VS Code).
2. Saisis le nom d'une ville et valide pour afficher la météo.
